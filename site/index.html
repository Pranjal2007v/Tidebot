A maintainer's assistant for GitHub

Tidebot handles the repetitive chores of running an open-source repo: labeling, duplicate checks, first-pass code review, reminders and merging. You spend your time on the work that matters.

Install on GitHub See the commands

What it does

Triage new issues

Labels each issue by content, adds triage until a maintainer looks, and flags likely duplicates among open issues.

First pass on every PR

Adds a size label, lints the title and description, and assigns reviewers by code area.

Code review on request

/review-sc posts up to 12 inline suggested changes, each checked against the real lines in the file.

Merge when it's ready

/merge waits for green CI and an approval. /hold and /wip keep a PR out until you lift them.

How it looks in a thread

Start a line with :tide, not an @mention, so nobody gets pinged by accident.

maria commented

:tide /size

tidebot commented

This PR changes 84 lines: size/M.

maria commented

:tide /merge squash

tidebot commented

Not merging: it has no approval; CI is still running.
