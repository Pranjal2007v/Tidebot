AI

/ask Anyone

Answer a question using the issue or PR thread as context.

:tide /ask where is auth handled?

A short answer that points at the files or comments it used.

/changelog Anyone

Write a release-note line for the PR.

:tide /changelog

- Reminders can now be cancelled with /remind cancel (#42)

/chat Anyone

Talk with the model in the thread, with earlier /chat turns as context.

:tide /chat would a cache help here?

A reply that follows on from the earlier turns.

/checklist Anyone

Make a review checklist for a PR or a definition of done for an issue.

:tide /checklist

A GitHub task list of up to ten unticked items.

/docs Anyone

Suggest missing or outdated doc comments in the PR.

:tide /docs

Suggested docstrings, and a note when code changed but no docs did.

/estimate Anyone

Give a rough size and effort for an issue or PR.

:tide /estimate assuming no API changes

M, about a day, with up to three reasons.

/explain Anyone

Explain a PR's change from its diff, or an issue in plain words.

:tide /explain

A plain-language walk through what changes and why.

/perf Anyone

Look only for performance problems in the changed files.

:tide /perf

Findings such as repeated work in loops or quadratic searches.

/review Anyone

Run the review pipeline and post the findings in one comment.

:tide /review

A memo on what the PR does, then each verified finding by file.

/review-sc Anyone

Review the PR and post up to 12 findings as inline suggested changes.

:tide /review-sc

One PR review with suggestions you can commit from the diff view.

/roast Anyone

A light-hearted take on the PR's code, never on the people behind it.

:tide /roast

Three to five friendly lines, ending with something the PR does well.

/security Anyone

Look only for security problems in the changed files.

:tide /security

Findings such as injection, path traversal or secrets in code.

/summarize Anyone

Summarize a long issue or PR thread.

:tide /summarize

A few lines on where the discussion stands and what is still open.

/test Anyone

List the test cases the PR's code changes still need.

:tide /test edge cases for the parser

Up to eight test cases, each with a file, a name and what it checks.

Workflow

/approve Maintainer

Approve the PR as a GitHub review.

:tide /approve

An approving review is posted.

/assign Collaborator (self), Maintainer (others)

Assign yourself, or (as a maintainer) anyone else.

:tide /assign @me

The issue is assigned; no reply.

/cc Collaborator

Ask someone to look: a review request on a PR, a mention on an issue.

:tide /cc @alice

cc @alice

/close Maintainer

Close the issue or PR.

:tide /close

It is closed; no reply.

/duplicate Maintainer

Mark the issue as a duplicate of another and close it.

:tide /duplicate #123

Duplicate of #123

/hold Collaborator

Block a merge with do-not-merge/hold, or cancel to lift it.

:tide /hold

The hold label is added; no reply.

/label Maintainer

Add labels, or remove one with a leading minus.

:tide /label bug -question

Labels are updated; no reply.

/lgtm Collaborator

Add the lgtm label to a PR, or cancel to remove it.

:tide /lgtm

The lgtm label is added; no reply.

Collaborators can also write a bare /lgtm on its own line.

/lock Maintainer

Lock the conversation, with an optional reason, or cancel to unlock.

:tide /lock resolved

The conversation is locked; no reply.

/merge Maintainer

Merge the PR once CI is green and it has an approval.

:tide /merge squash

Not merging: it has no approval; CI is still running.

/milestone Maintainer

Set the milestone, or clear it.

:tide /milestone v1.0

The milestone is set; no reply.

/reopen Maintainer

Reopen a closed issue or PR.

:tide /reopen

It is reopened; no reply.

/retitle Maintainer

Change the title.

:tide /retitle Fix crash when the config file is empty

The title is changed; no reply.

/ship Maintainer

Approve and merge in one step, if nothing else blocks the merge.

:tide /ship

The PR is approved and merged.

/wip Collaborator

Mark a PR as work in progress, or cancel when it's ready.

:tide /wip

The do-not-merge/wip label is added; no reply.
