Dashboard

Commands run, queue wait times, reviews posted and duplicates caught for one repo, read from your Tidebot server's stats endpoint.

Sign in with GitHub

Sign in with GitHub to see the repos you can push to; the repo box then offers them. Or type the server's TIDEBOT_STATS_TOKEN to see every repo: it stays in this tab and is sent only to the server above. Either way the server must list this site in TIDEBOT_DASHBOARD_ORIGINS.

Tidebot is in early development. Feedback on the command list is welcome on GitHub.
